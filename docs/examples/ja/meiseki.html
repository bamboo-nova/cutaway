meiseki プラグイン構成図

形式: Claude Code プラグイン形式

概要: AI が書いた日本語文書から、二重否定や LLM 定型句など読解負荷の高い構文を削ぎ落とし、一読で意味が取れる本文へ書き直すプラグイン。

  • 凡例:
  • オーケストレータ
  • スキル
  • 参照知識スキル
  • ゲート/監査
  • エージェント
  • MCPサーバー
  • スクリプト
  • データ/成果物
  • 破線=参照・データ ／ 赤破線枠=隔離境界 ／「不可視」=この環境でソース未マウントのため確認不可（0ではない）

実行フロー（Skills レイヤー）ノードをクリックで関連を強調 ／ ドラッグで移動 ／ ホイールで拡大縮小

呼び出し例（代表トレース）

  1. 1. 〔user〕 「この README をわかりやすく直して」-> meiseki 発動
  2. 2. 〔meiseki〕 全文を読み、否定・条件・係り受けの論理構造を確定させる（Step 1）
  3. 3. 〔textlint (npx)〕 JSON 出力から ruleId と行番号を取得し高負荷箇所を特定（Step 2）
  4. 4. 〔meiseki〕 patterns.md の A→H 順にリライト。二重否定の畳み込みが最優先（Step 4）
  5. 5. 〔meiseki〕 意味の検算: 真偽の反転・条件・数値の一致を原文と突き合わせる（Step 5）
  6. 6. 〔textlint (npx)〕 再実行で after < before を検算。二重否定は原則 0 件（Step 6）
  7. 7. 〔meiseki〕 やりすぎチェックを通し、リライト後の本文だけを返す（Step 7-8）
cutaway が structure YAML（plugin-structure/v1.1、meiseki 0.5.0）から決定論的に生成。図は派生物であり、構造の変更は YAML の差分で扱う。
