hookify プラグイン構成図

形式: Claude Code プラグイン形式

概要: 会話ログから防ぎたい挙動を見つけ、.local.md のルールファイルとして Claude Code のフックに変換するプラグイン（Anthropic 製）。

  • 凡例:
  • オーケストレータ
  • スキル
  • 参照知識スキル
  • ゲート/監査
  • エージェント
  • MCPサーバー
  • スクリプト
  • データ/成果物
  • 破線=参照・データ ／ 赤破線枠=隔離境界 ／「不可視」=この環境でソース未マウントのため確認不可（0ではない）

実行フロー（Skills レイヤー）ノードをクリックで関連を強調 ／ ドラッグで移動 ／ ホイールで拡大縮小

list
設定済みルールの一覧表示
help
プラグインの使い方ヘルプ

呼び出し例（代表トレース）

  1. 1. 〔user〕 引数なしで /hookify を実行
  2. 2. 〔hookify（コマンド）〕 最初に writing-rules スキルを読み、ルール書式を把握
  3. 3. 〔conversation-analyzer〕 直近 20-30 メッセージから防ぎたい挙動を抽出（ツール・パターン・深刻度）
  4. 4. 〔hookify（コマンド）〕 AskUserQuestion で対象ルールと warn / block を確認
  5. 5. 〔hookify（コマンド）〕 .claude/hookify.<rule-name>.local.md を生成
  6. 6. 〔rule_engine.py〕 以後の PreToolUse 等でルールを評価
  7. 7. 〔rule_engine.py〕 一致時は警告を注入、action: block なら操作を拒否
cutaway が structure YAML（plugin-structure/v1.1、hookify）から決定論的に生成。図は派生物であり、構造の変更は YAML の差分で扱う。
