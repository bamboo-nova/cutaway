cutaway プラグイン構成図

形式: Claude Code プラグイン形式

概要: Claude Code / Agent Plugins 1.0 プラグインの構造を棚卸しし、レビュー可能な structure YAML（正本）と ELK 自動レイアウトの Excalidraw 構成図を決定的に生成するプラグイン（日英対応）。

  • 凡例:
  • オーケストレータ
  • スキル
  • 参照知識スキル
  • ゲート/監査
  • エージェント
  • MCPサーバー
  • スクリプト
  • データ/成果物
  • 破線=参照・データ ／ 赤破線枠=隔離境界 ／「不可視」=この環境でソース未マウントのため確認不可（0ではない）

実行フロー（Skills レイヤー）ノードをクリックで関連を強調 ／ ドラッグで移動 ／ ホイールで拡大縮小

呼び出し例（代表トレース）

  1. 1. 〔user〕 「meiseki プラグインを可視化して」-> visualize-plugin 発動
  2. 2. 〔extract.py〕 方言を自動判定し dirscan で棚卸し。TODO 付きドラフトを出力（Layer 1）
  3. 3. 〔visualize-plugin〕 role 付与・flow 設計・trace 記述で TODO を解消し、役割一覧をユーザーに確認（Layer 2）
  4. 4. 〔validate.js〕 --yaml で TODO 残存・語彙・参照解決を検査
  5. 5. 〔convert.js〕 ELK 自動レイアウトで .excalidraw を生成（Layer 3）
  6. 6. 〔validate.js〕 バインド座標・はみ出しを検査。再変換のバイト同一で決定性を確認
  7. 7. 〔user〕 excalidraw.com で目視確認。直したい点は YAML に反映して再変換
cutaway が structure YAML（plugin-structure/v1.1、cutaway 0.1.0）から決定論的に生成。図は派生物であり、構造の変更は YAML の差分で扱う。
