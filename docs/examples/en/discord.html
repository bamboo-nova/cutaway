Example invocation (representative trace)

  1. 1. [user] pastes the bot token -> configure saves it to .env
  2. 2. [configure] explains the default pairing policy and reach (the Public Bot setting)
  3. 3. [discord] replies to an unknown sender's DM with a 6-char code and drops the message
  4. 4. [user] approves the sender with /discord:access pair <code>
  5. 5. [access] adds them to allowFrom in access.json; the server re-reads per message
  6. 6. [discord] forwards subsequent DMs into the Claude Code session
  7. 7. [discord] replies via the reply tool; permission checks arrive as DMs with Allow/Deny buttons
