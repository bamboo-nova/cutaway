Example invocation (representative trace)

  1. 1. [user] "make this README easier to read" -> meiseki triggers
  2. 2. [meiseki] reads the full text and pins down negation, conditions and dependency logic (Step 1)
  3. 3. [textlint (npx)] collects ruleId and line numbers from the JSON output to locate high-load spots (Step 2)
  4. 4. [meiseki] rewrites in patterns.md A-to-H order; collapsing double negatives comes first (Step 4)
  5. 5. [meiseki] meaning check: truth values, conditions and numbers must match the original (Step 5)
  6. 6. [textlint (npx)] re-run verifies after < before; double negatives at zero in principle (Step 6)
  7. 7. [meiseki] passes the overcorrection check and returns only the rewritten text (Steps 7-8)
