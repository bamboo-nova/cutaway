Example invocation (representative trace)

  1. 1. [user] "visualize the meiseki plugin" -> visualize-plugin triggers
  2. 2. [extract.py] auto-detects the dialect, dirscans the inventory and emits a TODO-marked draft (Layer 1)
  3. 3. [visualize-plugin] resolves TODOs (roles, flow, trace) and confirms the role list with the user (Layer 2)
  4. 4. [validate.js] --yaml checks leftover TODOs, vocabulary and reference resolution
  5. 5. [convert.js] generates the .excalidraw with ELK auto-layout (Layer 3)
  6. 6. [validate.js] checks bound-text coords and overflow; re-conversion confirms byte-identical determinism
  7. 7. [user] opens it at excalidraw.com; fixes go into the YAML and re-convert
