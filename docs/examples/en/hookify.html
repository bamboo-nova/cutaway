Example invocation (representative trace)

  1. 1. [user] runs /hookify with no arguments
  2. 2. [hookify (command)] loads the writing-rules skill first to learn the rule format
  3. 3. [conversation-analyzer] extracts behaviors to prevent from the last 20-30 messages (tool, pattern, severity)
  4. 4. [hookify (command)] confirms target rules and warn / block via AskUserQuestion
  5. 5. [hookify (command)] writes .claude/hookify.<rule-name>.local.md
  6. 6. [rule_engine.py] evaluates the rules on subsequent PreToolUse and other events
  7. 7. [rule_engine.py] injects a warning on match; action: block rejects the operation
